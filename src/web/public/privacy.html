Privacy Policy

Last updated 31 July 2026

SteedlesCrypto (“the bot”) is a Discord bot providing crypto price lookups, price alerts, new-token scanning and third-party rug checks. This policy describes exactly what it stores, what it does not, and who else sees your data.

The bot is operated privately by an individual and is self-hosted. It is not a company product and is provided free of charge.

1. What the bot stores

The bot stores the minimum needed to do its job. Every field it keeps is listed below — there is nothing else.

What Why Kept for
Server, channel and feature settings, plus the Discord user ID of whoever last changed them So each channel behaves the way its admins configured it Until deleted, or the bot leaves the server
Price alerts: your Discord user ID, the server and channel, the token address and your target price To notify you when a token crosses your target Until the alert fires or you delete it
Coin trackers: your Discord user ID, the server and channel, and the token and pool you asked to watch To tell you when that coin’s 1-minute trend turns Until you remove it, or its chart goes dead
Dashboard sessions: your Discord user ID, username, avatar reference, and the IDs of servers where you hold Manage Server To keep you signed in and show only your servers 7 days, then deleted automatically
A record of which tokens have already been posted to which channel To avoid posting the same token twice 14 days, then deleted automatically
Newly created token addresses seen on public blockchain feeds To detect when a new token reaches a real exchange 48 hours, then deleted automatically

2. What the bot does not store

Message content is never stored. The Token Brief feature reads messages to find contract addresses in them. That reading happens in memory only. No message text, embed, attachment, author name or timestamp is written to disk or database at any point. The only thing taken from a message is the token address itself, which is used to query a rug checker and then discarded.

The bot also does not collect, store or process:

  • Your email address, real name, phone number or physical address
  • Your wallet addresses, balances, holdings or transaction history
  • Direct messages, voice activity, or any channel the bot has not been given access to
  • Message history — it only sees messages posted while it is online and present
  • IP addresses, device fingerprints, cookies for tracking, or any analytics

The only cookie set is a sign-in session cookie for the dashboard. It contains a random session identifier and nothing else. It is not used for tracking and there are no third-party cookies.

3. Reading messages

The bot uses Discord’s Message Content permission. It is used for one purpose: spotting contract addresses so it can look those tokens up. This applies only in channels where a server administrator has explicitly switched the Token Brief feature on, and only where the bot has been given access.

The resulting summary is posted in that channel, or sent as a direct message if the channel is configured that way. It contains only public market and contract data about the token — never anything about the person who posted it, beyond their display name and a link back to their message when it is sent privately.

If Token Brief is switched off — which is the default — the bot ignores messages entirely.

4. Who else receives data

To answer a question about a token, the bot queries public third-party services. It sends them only the token contract address. It never sends your identity, your server, your channel, or any message text.

  • DexScreener — prices, liquidity and trading pairs
  • GeckoTerminal — one-minute price candles for a pool, used by the coin tracker
  • RugCheck — Solana token risk reports
  • GoPlus Security — EVM token contract properties
  • honeypot.is — simulates a buy and sell to detect honeypots on Ethereum, BSC and Base
  • PumpPortal — a public feed of new Solana tokens (receive-only; nothing is sent)

Discord necessarily processes everything the bot sends and receives, under Discord’s own privacy policy. Cloudflare routes traffic to the dashboard and may log connection metadata under its own policy.

Nothing is sold, rented, or shared for advertising. There is no advertising in this service and no data is shared with advertisers or data brokers.

5. Where data is held

Data is stored in a database on self-hosted hardware in South Africa, reachable from the internet only through an encrypted Cloudflare tunnel. Access is restricted to the operator. The dashboard requires signing in with Discord, and only shows servers where you hold the Manage Server permission.

No system is perfectly secure. This is a personal, self-hosted project and is not certified against any security standard.

6. Your choices

  • Delete your alerts: run /alert clear in the server, which removes all of them immediately.
  • Stop the bot reading messages in a channel: ask an admin to disable Token Brief there, or remove the bot’s access to the channel.
  • Sign out of the dashboard: use the Sign out button, which deletes the session record.
  • Remove everything for a server: remove the bot from the server. Ask the operator to purge any remaining stored settings.
  • Request access or deletion: contact the operator using the details below. Requests are handled manually and honoured within 30 days.

Depending on where you live you may have rights under laws such as the GDPR or South Africa’s POPIA, including the right to access, correct, delete or object to processing of your data. The contact below is the route for exercising them.

7. Children

The bot is not directed at children. Discord requires users to be at least 13, or older where local law sets a higher age. Do not use this bot if you do not meet Discord’s minimum age.

8. Changes

This policy may change as the bot changes. The date at the top reflects the current version. Material changes will be announced in servers where the bot is active.
